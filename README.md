# Picture in Picture — Arc Style

Мод для **Zen + Sine**, вдохновлённый оформлением Picture in Picture в Arc Browser.

- Запуск через штатный пункт **«Картинка в картинке»** при правом клике по видео.
- Скруглённые кнопки **Back to Tab**, **Minimize**, **Close**; управление плавно исчезает сразу после ухода курсора.
- Крупная центральная кнопка воспроизведения с перемоткой по бокам.
- Домен источника сверху, тонкая полоса прогресса снизу.
- Один переключатель автоматического режима в настройках мода.
- Свободное перетаскивание с притягиванием к углам после отпускания.
- Плавные перелёты между углами свайпами Magic Mouse, без зажатия кнопки.
- Кнопка **Speed** со штатным выбором скорости вместо кнопки субтитров.
- При ширине окна меньше 650 px верхние кнопки становятся компактными иконками.

## Установка

1. Откройте настройки Zen → **Sine Mods**.
2. В поле установки из GitHub вставьте:

   ```text
   https://github.com/b2theh/ArcPictureInPicture
   ```

3. Разрешите в Sine установку JavaScript из неофициальных источников
   (**Enable installing JS from unofficial sources**).
4. Установите мод и полностью перезапустите Zen.

Для работы требуется Sine с поддержкой JavaScript. Один импорт `userChrome.css`
не включает автоматический PiP и не добавляет подписи кнопок.

## Что изменилось в 1.3.12

Панель Speed автоматически закрывается после выбора готовой скорости
или завершения изменения ползунка. Скорость применяет штатный обработчик Zen,
после чего мод снимает состояние `donthide` и оставшийся фокус с панели.
Кнопка скорости возвращается к обычному поведению наведения и скрытия,
без зависшего меню или подсказки с выбранным значением.

- Вниз — нижний угол на той же стороне.

## Использование

Запустите видео и нажмите по нему правой кнопкой → **Картинка в картинке**.
На YouTube первый клик открывает меню сайта: нажмите правой кнопкой ещё раз
или используйте Shift + правый клик для меню браузера.

В **Sine Mods → Picture in Picture — Arc Style** включите
**«Автоматический PiP на всех сайтах»**. При уходе с вкладки, сворачивании
или перекрытии окна браузера Zen откроет PiP, а при возвращении закроет его.
Автоматика изначально выключена. Мод временно управляет штатными настройками
PiP; при выгрузке последнего экземпляра скрипта прежние значения восстанавливаются.
После отключения или удаления мода рекомендуется перезапуск браузера.

«На всех сайтах» означает без списка разрешённых доменов. Сохраняются ограничения
Zen: видео должно воспроизводиться, иметь звук и быть доступно штатному PiP.
Muted-видео, неподдерживаемые плееры и отдельные защищённые источники могут
не открываться автоматически. Закрытие PiP вручную подавляет немедленное
повторное открытие по штатным правилам Zen.

Перемотка использует штатный шаг Zen **5 секунд** и штатные значки, а не 15
на референсе. Сохраняются регулятор звука, полноэкранный режим,
скорость воспроизведения и клавиатурное управление там, где их предоставляет Zen.

## Проверка

Разметка, сообщения PiP, карта окон и названия настроек сверены с исходниками
**установленного Zen 1.24b / Gecko 159**, а формат пакета — с установленным Sine.
Браузер не запускался и профиль не изменялся. Визуальная и интерактивная проверка
остаются пользователю. Совместимость с другими версиями требует проверки.

```sh
node --check pip.uc.js
node --test tests/pip.test.cjs
```

Тесты проверяют оба автоматических триггера, переключение режима, несколько окон,
повторную загрузку и восстановление исходных пользовательских настроек.
Также проверяются четыре угла, дисплей с отрицательными координатами,
свободное отрывание, отсутствие притягивания во время удержания, отмена жеста
и освобождение захвата указателя при выгрузке. Это проверки логики в модели
окна; реальное перетаскивание в Zen проверяется вручную.
Проверки свайпов охватывают четыре направления, промежуточные кадры анимации,
порог жеста, единицы прокрутки, подавление повторов от инерции, несколько
мониторов, прерывание перелёта и системное уменьшение движения.
Дополнительно проверяются скрытие точно через 3 секунды, отмена таймера
при возврате курсора, повторный отсчёт и показ управления с клавиатуры.

Проверьте лично: меню видео, Back to Tab, Minimize, Close, паузу, перемотку,
ползунок прогресса, маленькое окно, автооткрытие и возврат на вкладку,
свайпы Magic Mouse и изменение скорости через Speed.
